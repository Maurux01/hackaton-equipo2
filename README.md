# Unique Japanese Dishes – Interactive Menu & Shopping Cart

Una aplicación web que muestra una selección curada de platos japoneses únicos y exóticos. Los usuarios pueden navegar por el menú, agregar ítems al carrito de compras con gestión de cantidades, marcar favoritos y filtrar entre el menú completo y los platos favoritos.

## Características

- **Menu interactivo**: tarjetas de productos renderizadas dinámicamente con nombre, descripción, imagen y precio.
- **Carrito de compras inteligente**: agrega productos, agrupados automáticamente por cantidad con subtotales y total calculado.
- **Sistema de favoritos**: marca platos como favoritos y filtra el menú para mostrar solo los ítems favoritos.
- **Alternar vista**: cambia entre "Todos los platos" y "Solo favoritos".
- **Formato de precio**: precios formateados en pesos colombianos (COP) usando `toLocaleString`.
- **Diseño responsivo**: construido con Bootstrap 5 para diseños adaptados a móviles.

## Uso

- Explora **"La carta de hoy"** para ver todos los platos disponibles.
- Haz clic en **Agregar** para añadir un plato al carrito. Las adiciones repetidas aumentan el contador de cantidad en lugar de duplicar la fila.
- Haz clic en **♡ / ♥️** en cualquier plato para añadirlo o quitarlo de tus favoritos.
- Usa **"♥️ Favoritos"** para filtrar el menú y mostrar solo tus platos favoritos.
- Usa **"Toda la carta"** para volver a la vista del menú completo.
- La sección del carrito (`Tu pedido es:`) se actualiza automáticamente con subtotales y total.
